🔗 **Live Website**: [https://portfolio-liart-rho-4sr7qde1ei.vercel.app](https://portfolio-liart-rho-4sr7qde1ei.vercel.app)

## ✨ Features

- **🎨 Dynamic Light / Dark Mode**: Custom theme toggle with persistent state and seamless transition animations.
- **⚡ Lightning Fast Performance**: Powered by Vite 6 and React 19 for instant page loads and fast HMR.
- **📱 Fully Responsive Design**: Beautiful typography and UI crafted specifically for desktop, tablet, and mobile displays.
- **✨ Smooth Animations**: Motion-driven components using Framer Motion (animated text, scroll reveals, floating effects).
- **📂 Section Breakdown**:
  - **Hero**: Introduction & typing role animation.
  - **Education**: Details about Computer Science Engineering degree at RVITM, Bengaluru.
  - **Projects**: Highlights of AI, Computer Vision, and Full-Stack web projects with GitHub links.
  - **Technical Skills**: Visual breakdown of languages, web tech, tools, and areas of interest.
  - **Contact & Footer**: Quick links to GitHub, LinkedIn, email, and phone contact.

## ⚙️ Getting Started Locally

To run this project on your local machine, follow these steps:

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher)
- `npm` or `pnpm` / `yarn`

### 2. Clone the Repository
```bash
git clone https://github.com/shivp7612/Portfolio.git
cd Portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 5. Build for Production
```bash
npm run build
```
